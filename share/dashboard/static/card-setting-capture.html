PFS Query Capture
Periodic snapshot of events_statements_summary_by_digest: flushes the digest table at each period and writes a timestamped log_pfs_queries_<date>.jsonl file with one templated query per line. OnOff
PFS Query Capture Period (hours)
How often (in hours) the PFS digest table is snapshotted and reset. Default: 1.
PFS Query Explain Cache
Run EXPLAIN for each new query template at snapshot time and persist the plan to pfs_explain_cache.jsonl. New templates are prioritised; existing plans are refreshed oldest-first. OnOff
PFS Explain Inter-Query Delay (ms)
Milliseconds to sleep between consecutive EXPLAIN calls during a snapshot to spread optimizer load. Set to 0 to disable. Default: 200.
PFS Explain Cache Purge Period (days)
Age in days after which a cached explain plan is evicted from memory and disk. Set to 0 to keep plans forever. Default: 30.
